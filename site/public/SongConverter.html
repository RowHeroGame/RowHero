Batch song converter

RowHero songs

Drop in as many Clone Hero song zips as you like (or song folders, or loose .chart / .mid files). Each one is converted to the game's chart .json with exact timing, and its audio stems are mixed into a single .wav. Nothing to fill in: the track, the song's sync delay, the artist, the length and the file name are all worked out for you.

Game file nameFromChartAudioStatus
Guitar charts often run fast streams on one fret, and folding orange onto R makes more of them. Leave this at 0 for the game. The game now applies this limit itself as each song loads, with its own value per regatta and boss song (NoteGap.cs), and Expert mode in Options turns it off to play every note. A chart converted with a gap here has those notes gone for good, so Expert mode cannot bring them back. Set it above 0 only if you want a chart thinned before it ever reaches the game: any note that comes sooner than this after the previous note in the same lane is then left out of the file. Notes in other lanes and chords are not affected.
The game's Songs folder is %USERPROFILE%\AppData\LocalLow\lfairclo\RowHero\Songs. "Save straight into" works in Chrome and Edge; pick that folder and the files are written into it, replacing any of the same name. The game uses a song's .wav before its .mp3, so old .mp3s can stay.
